# FocusFlow

FocusFlow is a student productivity platform designed to help students stay consistent with studying through mood tracking, Pomodoro sessions, task management, and study analytics.

## Features

- Mood Tracking
- Pomodoro Timer
- Daily Tasks
- XP System
- Streak Tracking
- Analytics Dashboard

## Tech Stack

- HTML
- CSS
- JavaScript
